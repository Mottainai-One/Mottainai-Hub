# Figma Prototype Documentation

This directory contains the reusable prototype source, UX references, final screenshots, and the final audit snapshot.

## Structure

- `assets/`: shared fonts, icons, and images used by the prototype.
- `auditoria/capturas/`: curated screenshots for the final review.
- `auditoria/rodada24/`: final audit data and the before-state needed for traceability.
- `css/`, `html/`, `js/`, and `jsp/`: prototype implementation files.
- `referencias/`: approved Figma reference images and font references.
- `tools/`: reusable scripts only; generated logs, caches, archives, and intermediate rounds are intentionally excluded.

Intermediate audit rounds and generated artifacts were removed from version control to keep the repository focused, reproducible, and lightweight. The final audit snapshot remains available for traceability.
