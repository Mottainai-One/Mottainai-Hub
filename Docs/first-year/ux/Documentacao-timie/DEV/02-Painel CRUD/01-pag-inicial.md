# Página Inicial (Dashboard)

**Arquivo:** `PaginaInicial.html`

## Estrutura
- **Cards de Resumo:** 4 cards no topo exibindo contadores (Empresas ativas, Lojas ativas, Funcionários ativos, Contas de usuários ativas).
- **Tabela de Cadastros Recentes:** Lista os últimos 6 registros adicionados ao sistema, mostrando Nome, Tipo de cadastro, Data e Situação.

## Funcionalidades Técnicas
- O body possui o atributo `data-pagina="inicio"`, que o CSS usa para destacar o item correto na Sidebar.
