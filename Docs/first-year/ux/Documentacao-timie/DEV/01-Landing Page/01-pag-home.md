# Página: Home

**Arquivo:** `index.html`

## Funcionalidades Implementadas
- **Hero Section:** Apresenta a frase principal ("Seu estoque é bom demais para ser desperdiçado") e botões de CTA (Entre em contato / Saiba mais).
- **Big Numbers:** Exibição de dados sobre o impacto do desperdício.
- **Funcionalidades Inteligentes:** Cards estáticos mostrando os recursos do sistema (alerta, controle de validade, previsão por IA).
- **Navegação Fixa:** Header (`position: fixed`) com links para Home, Sobre Nós, Planos e botão de contato.

## Destaques Técnicos
- Desenvolvimento responsivo para formato mobile e tablet
- Uso de variáveis no :root
- Uso de layout flexbox para alinhamento dos cards de funcionalidades.
