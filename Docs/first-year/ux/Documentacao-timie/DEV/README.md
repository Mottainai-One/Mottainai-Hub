# Desenvolvimento (Front-end)

Esta pasta documenta a implementação técnica do front-end do projeto Mottainai, dividida em duas frentes principais:
1. **Landing Page:** Página institucional para conversão de clientes.
2. **Painel CRUD:** Sistema administrativo web para gestão de cadastros (Empresas, Lojas, Funcionários, etc.).

**Tecnologias:** HTML5, CSS3, JavaScript puro (Vanilla JS).
