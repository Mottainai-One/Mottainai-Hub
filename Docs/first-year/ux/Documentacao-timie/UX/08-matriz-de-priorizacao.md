# Matriz de Priorização (MoSCoW e Severidade)

As matrizes foram utilizadas para transformar os achados dos testes em um backlog acionável para a equipe de desenvolvimento.

## Critérios de Pontuação
- **Severidade:** 0 (Sem importância) a 4 (Catastrófico).
- **Impacto:** Pontuação baseada na severidade + número de entrevistas que relataram o problema.
- **Esforço:** B (Baixo), M (Médio), A (Alto).

## Resumo da Priorização - Landing Page
