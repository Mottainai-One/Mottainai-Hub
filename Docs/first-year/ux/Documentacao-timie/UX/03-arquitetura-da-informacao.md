# Arquitetura da Informação

## Site Map: Landing Page
- *Home* (`index.html`)
  - Hero (Proposta de valor)
  - Funcionalidades
  - Big Numbers (Impacto)
- *Sobre Nós* (`sobre-nos.html`)
  - Carrossel (Significado, Proposta, Ideal, Produto)
  - Nossa Equipe (1º e 2º ano)
- *Planos* (`planos.html`)
  - Toggle Mensal/Anual
  - Cards de Planos
  - Dúvidas Frequentes (FAQ)
- *Contato* (Modal/Mailto)

## Fluxo: Painel Administrativo CRUD
- Login
- Dashboard (Página Inicial)
- Menu Lateral (Sidebar)
  - Empresas (Listagem -> Criar / Editar / Ver / Excluir)
  - Lojas
  - Funcionários
  - Cargos
  - Contas de Usuários
  - Planos de Assinatura
  - Endereços
