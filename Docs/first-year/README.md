# Documentação do Primeiro Ano

Esta pasta reúne a documentação produzida no primeiro ano do projeto Mottainai.

## Organização

- `ia/`: fontes, regras, memoriais e testes adversariais relacionados à inteligência artificial.
- `lpr/`: documentação de Linguagem de Programação e Raciocínio.
- `poo/`: documentação de Programação Orientada a Objetos, JDBC e Spring.
- `ux/`: documentação de UX, desenvolvimento, protótipos, auditorias e respectivos recursos visuais.

Os documentos do segundo ano continuam nas pastas já existentes diretamente em `Docs/`. Esta pasta foi criada para manter os dois períodos separados.
