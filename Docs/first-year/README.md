# First-Year Documentation

This directory contains the documentation produced during the first year of the Mottainai project.

## Structure

- `ia/`: artificial-intelligence sources, rules, memorials, and adversarial tests.
- `lpr/`: programming-language and reasoning documentation.
- `poo/`: object-oriented programming, JDBC, and Spring documentation.
- `ux/`: UX research, development notes, prototypes, audits, and visual assets.

The second-year documentation remains in the existing directories under `Docs/`. Keeping this directory isolated prevents the two academic periods from being mixed.
