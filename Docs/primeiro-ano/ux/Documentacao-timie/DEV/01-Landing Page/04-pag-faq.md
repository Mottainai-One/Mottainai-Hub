# Página: FAQ (Perguntas Frequentes)

**Arquivo:** `faq.html` / `faq.css` (ou integrado à `planos.html`)

## Objetivo da Página
Sanar dúvidas pré-contratação dos clientes, reduzindo a fricção no funil de vendas. A página foi planejada para receber as dúvidas que surgiram nas entrevistas de UX (como cálculo de sugestão de compra, sazonalidade e integração com sistemas legados).

## Funcionalidades Implementadas
- **Acordeão (Accordion):** Sistema de "abrir e fechar" as perguntas para não poluir a tela com muito texto de uma vez (implementado via CSS puro ou JS).
- **Agrupamento por Categorias:** (Ex: *Dúvidas sobre o Sistema*, *Dúvidas sobre Planos e Contratação*, *Dúvidas sobre Integração*).
- **CTA de Contato:** Botão ao final da página direcionando para `mailto:mottainai.contato@gmail.com` caso a dúvida não seja resolvida.
